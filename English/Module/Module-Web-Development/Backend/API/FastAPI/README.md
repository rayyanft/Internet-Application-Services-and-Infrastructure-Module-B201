# FastAPI

FastAPI is a Python framework for building HTTP APIs. It uses Python type hints to validate and document request and response data, and can generate interactive OpenAPI documentation. It is a framework choice, not an API style: a FastAPI service can expose REST-like endpoints.

Use it when a team works in Python, wants typed request/response models, and benefits from generated API documentation. It is not the right choice if the project requires a JavaScript-only runtime or the team cannot operate Python services. Learn HTTP and API design first; the framework does not replace authentication, authorization, validation, or careful error handling.

Official guide: [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/).
