# SOAP

SOAP is a protocol for exchanging structured messages, commonly using XML and formal service contracts such as WSDL. It is distinct from REST and GraphQL and is often found in established enterprise or government integrations.

Use SOAP when a partner system explicitly requires its contract, tooling, or WS-* features. For a new public web or mobile API without that constraint, REST or GraphQL is often easier to consume. SOAP messages and contracts can be more verbose, so do not select it without a compatibility or governance reason.

Reference: [W3C SOAP 1.2](https://www.w3.org/TR/soap12/).
