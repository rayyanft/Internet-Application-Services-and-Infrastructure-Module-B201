# Backend

Backend code runs on a server or managed service. It validates requests, applies application rules, accesses data, and returns a response. It is different from the frontend, which runs in the user's browser.

## Topics in This Folder

| Folder | Focus | Use it for |
| --- | --- | --- |
| [API](./API/README.md) | HTTP communication and API approaches such as REST, FastAPI, GraphQL, and SOAP. | Defining how clients request or change server data. |
| [Backend](./Backend/README.md) | Server routes and request/response handling. | Learning the responsibilities and structure of a simple server. |
| [JavaScript](./JavaScript/README.md) | Language fundamentals, including asynchronous code. | Writing browser or server application logic. |
| [Node.js](./Node.js/README.md) | JavaScript runtime outside the browser. | Running server programs, command-line tools, or development utilities. |

These technologies are related but not interchangeable: JavaScript is a language, Node.js is a runtime, an API is a communication contract, and backend is a system role. A typical learning path is JavaScript, Node.js, server fundamentals, then API design and database integration.
