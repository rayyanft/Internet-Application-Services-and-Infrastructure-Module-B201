# MySQL

MySQL is a relational database management system (RDBMS). It stores data in tables, supports SQL, and is commonly deployed as a database server for web applications.

Use MySQL when the application has structured relationships, the team or hosting provider already supports it, and its SQL features meet the query and consistency requirements. Choose SQLite for a simple local file-based exercise; compare PostgreSQL when the project needs its specific advanced SQL features. MySQL is an engine you operate or host, not a complete backend platform.

Before production use, define backups, access permissions, schema migrations, connection limits, and parameterized query practices. Official manual: [MySQL 8.4 Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/).
