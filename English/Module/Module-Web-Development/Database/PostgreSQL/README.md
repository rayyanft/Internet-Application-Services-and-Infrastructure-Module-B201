# PostgreSQL

PostgreSQL is an open-source relational database management system with strong SQL support, transactions, constraints, and a broad set of built-in and extensible data types.

Choose PostgreSQL when relational integrity, complex queries, or PostgreSQL capabilities such as JSONB and extensions matter, and the team can operate or obtain a managed instance. MySQL can be a better fit when a project's existing hosting, expertise, or platform standard favors it. PostgreSQL is a database engine, while Supabase is a hosted platform built around PostgreSQL with additional services.

Plan for schema migrations, backups, roles, connection management, and monitoring. Official documentation: [PostgreSQL Documentation](https://www.postgresql.org/docs/).
