# Supabase

Supabase is a managed backend platform built around PostgreSQL. Depending on the plan and configuration, it provides a hosted database and services such as authentication, APIs, storage, and realtime features. It is not a new SQL database engine: its relational database is PostgreSQL.

Use Supabase when a project wants managed PostgreSQL and integrated backend services without assembling each service separately, and its pricing, region, access model, and operational constraints fit. Choose a self-managed PostgreSQL deployment when direct infrastructure control is essential. Firebase may be more suitable when its document/realtime data model and ecosystem are a better match.

Design Row Level Security and authentication deliberately; a public client key is not a substitute for database policies. Check quotas, backups, data export, and migration options. Official docs: [Supabase Documentation](https://supabase.com/docs).
