# Frontend

Frontend is the browser-facing part of a web application. It presents information, responds to user input, and communicates with APIs when it needs server data.

## Topics in This Folder

| Folder | Difference | Typical use |
| --- | --- | --- |
| [HTML](./HTML/README.md) | Markup that defines content and its semantic structure. | Headings, forms, navigation, and meaningful page sections. |
| [CSS](./CSS/README.md) | Styling and layout language for HTML. | Responsive layouts, colors, typography, and interaction states. |
| [Tailwind CSS](./TailwindCSS/README.md) | A utility-first CSS framework applied through class names. | Building consistent interfaces quickly when utility classes fit the project. |
| [React.js](./React.js/README.md) | A JavaScript library for component-based user interfaces. | Interfaces with reusable components and changing data/state. |
| [Frontend](./Frontend/README.md) | A small browser-side example that combines the concepts. | Practicing how markup, styling, and client-side behavior fit together. |

Start with HTML, then CSS, and then JavaScript. Add React or Tailwind when the project benefits from their component or styling approach; neither replaces understanding HTML and CSS fundamentals.
