# Modul: Pengembangan Aplikasi Mobile

Modul ini membawa pemula dari widget Flutter hingga integrasi API. Setiap bagian berdiri sebagai submodul; kerjakan berurutan dan jalankan contoh hanya di emulator atau perangkat uji yang Anda kendalikan.

## Teori Dasar

Aplikasi mobile berjalan pada perangkat dengan ukuran layar, siklus hidup, dan koneksi yang dapat berubah. Flutter dan React Native menawarkan cara membangun antarmuka lintas platform, tetapi menggunakan bahasa serta pola yang berbeda. State menggambarkan data yang sedang ditampilkan; API memungkinkan aplikasi memperoleh data dari layanan lain.

Pelajari empat tahap berikut: [1-Flutter-Dasar](./1-Flutter-Dasar/README.md), [2-React-Native-Dasar](./2-React-Native-Dasar/README.md), [3-State-Management](./3-State-Management/README.md), dan [4-Mobile-API-Integration](./4-Mobile-API-Integration/README.md). Analogi: widget adalah komponen furnitur, state adalah catatan kondisi ruangan, dan API adalah petugas yang mengambil informasi dari bagian lain.

## Alat dan Persiapan Praktikum

- Komputer dan editor kode seperti VS Code.
- Flutter SDK untuk submodul Flutter; Node.js versi LTS dan Expo untuk React Native.
- Emulator Android/iOS atau perangkat uji yang Anda miliki serta koneksi jaringan.
- Periksa panduan resmi platform untuk instalasi dan lisensi. Emulator membutuhkan ruang disk dan memori.
- Jangan memasukkan token, kata sandi, maupun data pribadi ke contoh atau repositori.

## Langkah-Langkah Praktikum (Hands-on)

1. Selesaikan pengenalan Flutter dan pastikan aplikasi contoh berjalan.
2. Buat proyek React Native baru dengan Expo dan bandingkan struktur komponennya.
3. Tambahkan state lokal untuk tombol penghitung, lalu amati kapan tampilan berubah.
4. Pelajari submodul State Management sebelum memindahkan state ke komponen bersama.
5. Ikuti submodul integrasi API; uji kondisi memuat, berhasil, dan gagal.
6. Catat perangkat, versi SDK, perintah yang dijalankan, serta hasil uji.

## Tugas Modul

Buat prototipe aplikasi informasi layanan laboratorium dengan satu layar daftar, status pemuatan, dan pesan ketika data gagal dimuat. Implementasikan antarmuka dalam Flutter atau React Native, jelaskan keputusan state management, dan gunakan hanya data publik atau fiktif.
