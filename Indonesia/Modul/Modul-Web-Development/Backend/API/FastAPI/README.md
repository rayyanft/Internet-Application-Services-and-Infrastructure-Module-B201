# FastAPI

FastAPI adalah framework Python untuk membangun API HTTP. FastAPI memakai type hint Python untuk memvalidasi dan mendokumentasikan data request serta respons, dan dapat membuat dokumentasi OpenAPI interaktif. FastAPI adalah pilihan framework, bukan gaya API: layanan FastAPI dapat menyediakan endpoint bergaya REST.

Gunakan FastAPI ketika tim menggunakan Python, membutuhkan model request/respons bertipe, dan terbantu oleh dokumentasi API otomatis. FastAPI kurang tepat jika proyek hanya mengizinkan runtime JavaScript atau tim tidak dapat mengoperasikan layanan Python. Pelajari HTTP dan desain API terlebih dahulu; framework tidak menggantikan autentikasi, otorisasi, validasi, atau penanganan error yang baik.

Panduan resmi: [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/).
