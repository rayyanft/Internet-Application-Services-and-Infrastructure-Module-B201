# SOAP

SOAP adalah protokol pertukaran pesan terstruktur, umumnya menggunakan XML dan kontrak layanan formal seperti WSDL. SOAP berbeda dari REST dan GraphQL serta sering ditemukan pada integrasi enterprise atau pemerintahan yang sudah berjalan.

Gunakan SOAP jika sistem mitra secara eksplisit mewajibkan kontrak, alat, atau fitur WS-* tersebut. Untuk API web atau mobile baru tanpa kewajiban itu, REST atau GraphQL sering lebih mudah digunakan. Pesan dan kontrak SOAP dapat lebih panjang, jadi pilih hanya jika ada alasan kompatibilitas atau tata kelola.

Referensi: [W3C SOAP 1.2](https://www.w3.org/TR/soap12/).
