# Backend

Backend berjalan di server atau layanan terkelola. Backend memvalidasi request, menjalankan aturan aplikasi, mengakses data, lalu mengirim respons. Ini berbeda dari frontend yang berjalan di browser pengguna.

## Topik dalam Folder Ini

| Folder | Fokus | Digunakan untuk |
| --- | --- | --- |
| [API](./API/README.md) | Komunikasi HTTP dan pendekatan API seperti REST, FastAPI, GraphQL, dan SOAP. | Menentukan cara client meminta atau mengubah data di server. |
| [Backend](./Backend/README.md) | Route server dan penanganan request/respons. | Mempelajari tanggung jawab serta struktur server sederhana. |
| [JavaScript](./JavaScript/README.md) | Dasar bahasa, termasuk kode asinkron. | Menulis logika aplikasi di browser atau server. |
| [Node.js](./Node.js/README.md) | Runtime JavaScript di luar browser. | Menjalankan program server, alat command-line, atau utilitas pengembangan. |

Teknologi ini saling berhubungan, tetapi tidak dapat saling menggantikan: JavaScript adalah bahasa, Node.js adalah runtime, API adalah kontrak komunikasi, dan backend adalah peran sistem. Urutan belajar yang umum adalah JavaScript, Node.js, dasar server, lalu desain API dan integrasi database.
