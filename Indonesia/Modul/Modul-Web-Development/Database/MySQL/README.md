# MySQL

MySQL adalah sistem manajemen database relasional (RDBMS). MySQL menyimpan data dalam tabel, mendukung SQL, dan umum dijalankan sebagai database server untuk aplikasi web.

Gunakan MySQL ketika aplikasi memiliki relasi data terstruktur, tim atau penyedia hosting sudah mendukungnya, dan fitur SQL-nya memenuhi kebutuhan query serta konsistensi. Pilih SQLite untuk latihan lokal sederhana berbasis file; bandingkan dengan PostgreSQL jika proyek membutuhkan fitur SQL lanjutan tertentu. MySQL adalah mesin database yang dioperasikan atau di-host, bukan platform backend lengkap.

Sebelum digunakan di produksi, tentukan pencadangan, izin akses, migrasi skema, batas koneksi, dan praktik query berparameter. Manual resmi: [MySQL 8.4 Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/).
