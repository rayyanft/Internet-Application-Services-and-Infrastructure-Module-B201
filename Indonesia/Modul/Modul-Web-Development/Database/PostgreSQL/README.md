# PostgreSQL

PostgreSQL adalah sistem manajemen database relasional open-source dengan dukungan SQL yang kuat, transaksi, constraint, serta banyak tipe data bawaan dan yang dapat diperluas.

Pilih PostgreSQL jika integritas relasional, query kompleks, atau kemampuan khusus seperti JSONB dan extension dibutuhkan, serta tim mampu mengoperasikan instance sendiri atau terkelola. MySQL dapat lebih sesuai jika hosting, keahlian tim, atau standar platform yang sudah ada mendukungnya. PostgreSQL adalah mesin database, sedangkan Supabase merupakan platform terkelola berbasis PostgreSQL dengan layanan tambahan.

Rencanakan migrasi skema, pencadangan, role, pengelolaan koneksi, dan monitoring. Dokumentasi resmi: [PostgreSQL Documentation](https://www.postgresql.org/docs/).
