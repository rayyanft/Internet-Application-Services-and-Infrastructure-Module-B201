# Supabase

Supabase adalah platform backend terkelola yang dibangun di atas PostgreSQL. Bergantung pada paket dan konfigurasi, Supabase menyediakan database ter-host serta layanan seperti autentikasi, API, penyimpanan file, dan fitur realtime. Supabase bukan mesin database SQL baru: database relasionalnya adalah PostgreSQL.

Gunakan Supabase ketika proyek membutuhkan PostgreSQL terkelola dan layanan backend terintegrasi tanpa menyusun setiap layanan sendiri, serta harga, region, model akses, dan batas operasionalnya sesuai. Pilih PostgreSQL yang dikelola sendiri jika kendali langsung atas infrastruktur sangat penting. Firebase dapat lebih cocok jika model data dokumen/realtime dan ekosistemnya lebih sesuai.

Rancang Row Level Security dan autentikasi dengan benar; kunci client publik bukan pengganti kebijakan database. Periksa kuota, backup, ekspor data, dan opsi migrasi. Dokumentasi resmi: [Supabase Documentation](https://supabase.com/docs).
