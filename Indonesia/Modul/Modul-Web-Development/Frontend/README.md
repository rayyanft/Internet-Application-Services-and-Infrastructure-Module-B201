# Frontend

Frontend adalah bagian aplikasi web yang berhadapan dengan browser. Bagian ini menampilkan informasi, merespons masukan pengguna, dan berkomunikasi dengan API ketika membutuhkan data server.

## Topik dalam Folder Ini

| Folder | Perbedaan | Kegunaan umum |
| --- | --- | --- |
| [HTML](./HTML/README.md) | Markup untuk menentukan konten dan struktur semantiknya. | Judul, formulir, navigasi, dan bagian halaman yang bermakna. |
| [CSS](./CSS/README.md) | Bahasa gaya dan tata letak untuk HTML. | Tata letak responsif, warna, tipografi, dan kondisi interaksi. |
| [Tailwind CSS](./TailwindCSS/README.md) | Framework CSS utility-first yang diterapkan melalui nama class. | Membuat antarmuka konsisten dengan cepat jika utility class sesuai proyek. |
| [React.js](./React.js/README.md) | Library JavaScript untuk antarmuka berbasis komponen. | Antarmuka dengan komponen yang dapat digunakan ulang dan data/state yang berubah. |
| [Frontend](./Frontend/README.md) | Contoh sisi browser kecil yang menggabungkan konsep-konsep tersebut. | Berlatih menghubungkan markup, gaya, dan perilaku sisi client. |

Mulai dari HTML, lalu CSS, kemudian JavaScript. Tambahkan React atau Tailwind bila proyek terbantu oleh pendekatan komponen atau styling-nya; keduanya tidak menggantikan pemahaman dasar HTML dan CSS.
