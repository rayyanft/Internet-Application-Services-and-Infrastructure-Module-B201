## About This Curriculum / Tentang Kurikulum Ini

### English
This repository contains a comprehensive laboratory internship curriculum designed for students starting from scratch. It guides learners step-by-step through:
- **UI/UX Design**: User problem framing, user flows, wireframing, and interactive prototyping in Figma.
- **Web Development**: HTML semantic structure, CSS & responsive design, Tailwind CSS, modern browser JavaScript, Node.js CLI scripting, React.js component architecture, REST APIs, Express backend services, frontend DOM interactivity, and SQLite database fundamentals.
- **Mobile Application Development**: Google Flutter basics, React Native with Expo, cross-platform state management, and mobile API network integration.
- **Server Infrastructure & Deployment**: Linux Ubuntu server administration, Nginx HTTP web server configuration, Docker containerization, and modern deployment strategies (VPS, Vercel, Docker).
- **Capstone Practice Project**: Building and deploying a unified, responsive Laboratory Information Portal.

### Bahasa Indonesia
Repositori ini berisi kurikulum magang laboratorium komprehensif yang dirancang untuk mahasiswa yang memulai dari nol. Materi menuntun peserta langkah demi langkah melalui:
- **Perancangan UI/UX**: Perumusan masalah pengguna, user flow, wireframe, dan prototipe interaktif di Figma.
- **Pengembangan Web**: Struktur semantik HTML, CSS & desain responsif, Tailwind CSS, JavaScript browser modern, skrip CLI Node.js, arsitektur komponen React.js, REST API, layanan backend Express, interaktivitas DOM frontend, dan dasar database SQLite.
- **Pengembangan Aplikasi Mobile**: Dasar Google Flutter, React Native dengan Expo, manajemen state lintas platform, dan integrasi API pada mobile.
- **Infrastruktur Server & Deployment**: Administrasi server Linux Ubuntu, konfigurasi web server Nginx, container Docker, dan strategi deployment modern (VPS, Vercel, Docker).
- **Proyek Praktik Mandiri**: Membangun dan mempublikasikan Portal Informasi Laboratorium yang responsif dan fungsional.
